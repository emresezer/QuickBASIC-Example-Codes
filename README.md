<h1 align="center">🖥️ QuickBASIC Example Codes</h1>
<p align="center">
  <em>A collection of educational QuickBASIC programs demonstrating fundamental programming concepts</em>

<hr>

<h2>🎯 Purpose & Scope</h2>
<p>
  This repository serves as a curated collection of simple QuickBASIC programs designed to illustrate fundamental programming concepts such as:
</p>
<ul>
  <li>Input and output handling</li>
  <li>Control structures (if-else, loops)</li>
  <li>Arithmetic operations and functions</li>
  <li>Basic algorithm implementation</li>
</ul>
<p>
  These examples are intended for educational purposes, providing a foundation for beginners to understand and practice QuickBASIC programming.
</p>

<hr>

<h2>🧩 Project Structure</h2>

<pre>
📁 QuickBASIC-Example-Codes/
│
├── arithmetic.bas   → Demonstrates basic arithmetic operations
├── example.bas      → A simple introductory program
├── for.bas          → Example of a 'for' loop
├── goto.bas         → Demonstrates the use of 'goto' statement
├── if_else.bas      → Conditional logic using 'if-else'
├── if_then.bas      → Conditional logic using 'if-then'
├── input.bas        → Handling user input
└── while.bas        → Example of a 'while' loop
</pre>

<hr>

<h2>⚙️ Usage</h2>
<ol>
  <li>Ensure you have a QuickBASIC-compatible environment set up. You can use <a href="https://www.qb64.net/" target="_blank">QB64</a>, a modern QuickBASIC IDE.</li>
  <li>Download or clone this repository to your local machine.</li>
  <li>Open the desired .bas file in your QuickBASIC IDE.</li>
  <li>Run the program to observe its functionality and experiment with modifications.</li>
</ol>
